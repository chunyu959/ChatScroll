ChatScroll（中文名：聊卷）是一款轻量、完全离线的 Android 应用，用来阅读以 Markdown 导出的 AI 对话记录——你的消息在右边，AI 的回复在左边，就像真正的聊天软件一样。

## 功能

- **聊天式阅读**——用户消息是暖色气泡靠右，AI 回复是干净的纯文本靠左，暖色的米白 + 陶土橙配色
- **完整 Markdown 渲染**——标题、列表、引用、表格、任务清单、链接、图片
- **代码块语法高亮**——Java、Kotlin、Python、JavaScript、JSON、SQL、YAML、Go、C/C++ 等
- **LaTeX 数学公式**——行内 `$...$` 与独立 `$$...$$`
- **思维链可折叠**——导出文件里附带的推理过程会被收起来，点开才显示
- **对话库**——每个导入的文件都会保存到列表里（标题、消息条数、导入时间）。还没打开过的会标上「新」，点进去就消失。长按可以重命名、置顶、删除，也可以批量删除，置顶的对话始终排在最前
- **文件夹分类与排序**——全部/未分类/自建单层文件夹，支持创建、重命名、删除及单条/批量移动；按导入时间、显示名称自然顺序、原始 Markdown 大小正反向排序，置顶始终优先，记住筛选和排序
- **重复导入会先问你**——内容一模一样的对话再次导入时会提示，而不是默默存成两份。判断依据是内容本身，不是文件名
- **两种导入方式**——在 App 内点 **+**，或在系统里用「分享」把 `.md` 文件直接发给 ChatScroll
- **中英双语**——自动跟随系统语言
- **阅读操作**——分别复制正文/全部内容/代码、选择文本、消息目录、书签、跳到顶部/底部、全部展开/收起、图片全屏缩放；可切换纯阅读模式，隐藏编号和大操作栏
- **宽表格**——保留适合阅读的列宽、横向滑动和全屏浏览，不缩小正文；复杂引用/HTML上下文完整保留
- **解析历史与空间管理**——预览并恢复上次解析，保留当前版本以便反向恢复；按类别查看占用，确认后仅清理不再被恢复副本引用的较早历史
- **搜索与显示设置**——保留列表搜索词，点击结果跳到命中消息；阅读页高亮关键词；可调字号、行距及浅色/深色/跟随系统主题
- **原文与备份**——新导入保留 Markdown 原文，可查看/导出和指定格式重新解析；本地 ZIP 备份与恢复，恢复时合并而不覆盖现有记录
- **可靠存储**——原子保存、恢复副本、完整内容查重、图片和搜索索引分离；应用进程存活期间连续导入会排队处理
- **离线使用**——不申请网络权限，无账号、无追踪。Android 系统备份已启用，遵循设备设置；手动备份包含私人聊天内容，请妥善保存

## 支持的导入格式

ChatScroll 识别使用 `User` / `Assistant` 角色标记的聊天记录导出文件：

```markdown
# 对话标题

**User**:

帮我看看这个问题？

---

**Assistant**:

好的，我的建议是……

- 第一点
- 第二点
```

- ✅ 支持新旧 [RikkaHub](https://github.com/rikkahub/rikkahub) 角色标记导出，含思考、内嵌图片、围栏包裹的工具输入/输出、截断工具预览及工具输出中的图片。工具块在输出结束围栏处停止，保留工具之间的正常回复
- ✅ 支持 [Kelivo](https://github.com/Chevey339/kelivo) 导出格式（每条消息带时间和发言人，思考过程与工具调用默认折叠）
- ✅ 支持 [Chatbox](https://chatboxai.app) 导出格式（`**user**:` / `**assistant**:` 标记，正文写在代码块里，工具调用默认折叠）。Chatbox 的导出文件不包含图片和思考过程
- ✅ 其他任意 Markdown 文件——作为单个文档打开阅读
- 🔜 更多格式敬请期待

RikkaHub 把思考过程和普通引用都写成 `>`。应用会自动折叠助手消息开头、以及紧接工具后的引用；正常正文开始后，引用保留在正文。由于格式本身存在歧义，开头的普通引用仍可能被折叠。普通 Markdown 文档不作思考分类。Kelivo 没有明确结束标记的纯文本工具输出，仍需要启发式判断边界。

**升级到 1.5.0 后：** 原有记录仍可读取，元数据迁移不重写旧正文。新导入保留原文并使用第 2 版解析器。阅读菜单可查看/导出原文或重新解析；没有原文的旧记录会请你选择原文件。重解析保留上一存储版本、标题和置顶；消息分界变化时阅读位置及书签可能重置。备份包含对话、原文、图片及阅读元数据，不包含外观设置。恢复先校验全部文件，冲突时创建新副本。当前备份限制为单个条目 64 MiB、总计 256 MiB；损坏记录会提示并保留，不会悄悄遗漏导出或删除。

**1.5.1 显示修补：** Markdown 解析完成后才创建已填入正文的文字控件，避免空控件提前测量后留下错误尺寸；字号、行距改变时重新建立布局。本次无数据格式变化，不需要重新导入。旧版故障已真机复现并记录布局证据；用户反馈安装1.5.1后翻阅及最大/最小字号行距均未再见异常，自动化设备测试尚未执行。

**1.6.0 阅读与恢复：** 设置内开启纯阅读模式（默认保持关闭），通过紧凑菜单或长按进行消息操作；文字选择仍由原生控件处理。表格上方可进入全屏。阅读菜单“恢复上次解析结果”先预览再确认，仅对校验完整的历史开放；没有历史或旧历史缺少校验证据时不会猜测恢复。存储管理保留当前、上一次、额外恢复检查点及全部图片，只清理能明确验证的更早版本。清理预览后数据变化则需刷新，未知文件和不确定记录保留。未增加聊天追加合并功能。

**1.7.0 分类与排序：** 列表上方选择文件夹，在“管理文件夹”中创建、重命名或删除。删除只将对话移回未分类，不删除内容；长按或多选后可移动。排序支持时间正反向、名称A–Z/Z–A（数字按1、2、10）、原始文件大小正反向；使用当前显示名称，改名后顺序随之变化。大小按原文UTF-8字节数（含内嵌图片）计算，未知大小两种方向都排最后，不计解析副本占用。新导入默认未分类。备份格式2包含空文件夹和分类关系，恢复重名文件夹时建立独立改名副本；兼容旧格式1，新备份应使用1.7.0及以上恢复。

**1.8.0 外观与动效：** 延续暖米白与陶土色，统一标题、文字和圆角，设置页增加分组与阅读样张。设置入口移至首页右上角，导入使用带文字的按钮；卡片保留消息数、完整导入时间与原文大小，辅助信息可自动换行。选中卡片平滑改变底色和边框，排序与置顶使用位置过渡，搜索栏淡入切换，折叠箭头旋转，页面进入时轻微位移淡入。动效由 Compose 跟随系统动画缩放；长正文和折叠内容不做尺寸动画，保留1.5.1的原生文字测量流程。没有数据格式变化。181项离线测试通过，界面和动效尚待手机验证。

**1.9.0 动效整合：** 在1.8.0外观与基础动效上补齐批量工具栏／选择标记／导入按钮的淡入、微移与缩放，勾选与书签图标交叉淡入，阅读图标按钮增加按压反馈。单个思考／工具展开时共享透明度过渡，滚动回该块不会重新播放；批量展开直接显示。图片与表格全屏窗口统一开合过渡，退出完成后释放，图片解码完成淡入。普通滚动不做逐项入场，正文尺寸、图片手势和页面保存机制不变。181项离线测试通过，Release和AndroidTest编译通过。用户完成外观与动效验收并反馈暂未发现问题；自动化设备显示测试与系统零动画专项验证尚未执行。

## 下载安装

前往 [Releases](../../releases) 下载最新 APK，安装到 Android 8.0 及以上的设备即可。

## 从源码构建

环境要求：JDK 17+，Android SDK（平台 36），用 Android Studio 打开即可直接运行。

```bash
./gradlew assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

如需自行签名 release 包，在项目根目录创建 `keystore.properties`（已被 gitignore）：

```properties
storeFile=keystore/chatscroll.jks
storePassword=…
keyAlias=…
keyPassword=…
```

## 测试

```bash
./gradlew :app:testDebugUnitTest
```

普通测试使用脱敏的固定样例。五份真实回归文件留在仓库之外，需要验证时传入 `-PchatscrollCorpusDir="本地语料目录"`；文件名为 `CLAUDE（1）.md` 和 `claude（2）.md` 至 `claude（5）.md`。未配置目录时会明确跳过这项语料测试；配置后缺少文件则失败。检查包括角色与消息数、工具的精确范围、正文位置、图片引用，以及重叠历史的一致性。失败日志不会打印聊天正文。
